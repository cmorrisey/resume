# Final Reply Template

Champ reads replies on his phone between classes. Lead with the result, keep it tight, no em dashes, casual but professional. Use this order:

1. **Lead line:** the file name, "one page," that it reads cleanly for the ATS, and the single most important thing about this match (or a deadline warning if the posting closes soon).

2. **How I tailored it:** 4-7 numbered points. Each says what changed and which line of the posting it answers. Quote a new bullet when it is the key change.

3. **ATS match: about N%.** Then two bullets:
   - **Covered:** the posting keywords the resume now hits.
   - **Not claimed:** keywords left out because Champ has not done them, with one line on how to prep them for an interview.

4. **Skills tags** in a code block, one per line, most relevant first (for Workday or similar skills fields). Every tag must be backed by the resume.

5. **Check before you submit:** only real open items, each one line: unconfirmed claims used, assumed dates, eligibility gates (GPA floor, class standing, citizenship, graduation window), location/relocation/travel, term or start-date questions, whether to paste this version's bullets into the Work Experience fields.

6. One line on where the files are pushed.

Add-ons, only when asked or obviously needed:

- **Workday Work Experience blocks:** for each job, list Job Title, Company, Location, "I currently work here" (checked/unchecked), From/To as MM/YYYY, then the Role Description in a code block using "- " dashes (Workday text boxes garble "•"). Note that Leadership items sometimes autofill as jobs and should be deleted.
- **Coursework form text:** from references/claim-rules.md section 3, one course per line: `DEPT NUM - Title, Term, Grade`, grouped Cal Poly / West Point / AP.
- **Cover letter:** see SKILL.md step 8.
- **Sources:** when web research was used, end with a Sources list of markdown links.
